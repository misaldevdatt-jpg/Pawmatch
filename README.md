# PawMatch - Pet Adoption & Responsible Care Initiative

PawMatch is a React-based Single Page Application (SPA) designed to streamline pet adoptions, promote sterilization and vaccination awareness, and connect users with partner animal shelters and veterinary networks.

## Features
- **Pet Catalog & Search:** Browse available pets with health and sterilization badges.
- **AI Matcher:** Questionnaire-based pet matching tool.
- **Pet Care Initiative:** Comprehensive guides on vaccination schedules, spaying/neutering, and local partner welfare networks.
- **Admin Dashboard:** Real-time adoption request tracking using client-side state management.
- **Shop:** Essential supplies and medical resources for new pet owners.

## Tech Stack
- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Deployment:** Netlify (Continuous Deployment via GitHub)
